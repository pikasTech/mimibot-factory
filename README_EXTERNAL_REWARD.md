# 外部奖励系统使用指南

LLaMA-Factory GRPO训练支持外部奖励系统，允许通过网络连接从外部程序获取奖励信号。这使得可以实现更加复杂和定制化的奖励计算，而不受训练脚本本身的限制。

## 功能概述

外部奖励系统由以下部分组成：

1. **服务器端**：在GRPO训练脚本中启动的TCP服务器
2. **客户端**：实现奖励计算的外部程序
3. **接口协议**：服务器和客户端之间的JSON通信格式

外部奖励系统的工作流程如下：
1. 训练开始时，服务器自动启动并监听指定端口
2. 外部客户端连接到服务器
3. 训练过程中，服务器将模型生成的回复、输入提示和标准答案发送给所有连接的客户端
4. 客户端计算奖励并返回给服务器
5. 服务器将从所有客户端获取的奖励值累加，作为最终的奖励信号

## 使用方法

### 1. 在训练配置中启用外部奖励

在配置文件中添加以下行：

```json
{
    "additional_rewards": [
        {
            "name": "EXTERNAL",
            "weight": 1.0,  // 根据需要调整权重
            "port": 5678     // 可选，默认为5678
        }
    ]
}
```

### 2. 启动外部奖励客户端

使用提供的外部奖励客户端脚本：

```bash
python external_reward_client.py --host localhost --port 5678
```

或者开发自己的客户端，只需遵循通信协议即可。

### 3. 开始训练

正常启动训练脚本，外部奖励系统将自动运行。

## 通信协议

### 欢迎消息

客户端连接时，服务器发送欢迎消息：

```json
{
    "type": "hello",
    "message": "Connected to external reward server"
}
```

### 奖励请求

当需要计算奖励时，服务器发送奖励请求：

```json
{
    "type": "reward_request",
    "data": {
        "completions": ["<think>思考过程1</think>回复1", ...],
        "responses": ["回复1", ...],
        "prompts": ["提示1", ...],
        "answers": ["标准答案1", ...]
    }
}
```

### 奖励响应

客户端计算奖励后返回响应：

```json
{
    "rewards": [50.0, 75.0, ...]
}
```

## 开发自定义客户端

开发自定义客户端需要：

1. 创建TCP套接字连接到服务器
2. 接收并解析欢迎消息
3. 循环接收奖励请求
4. 计算奖励并返回响应

参考`external_reward_client.py`脚本，可以根据需要修改`calculate_reward`函数，实现自定义奖励计算逻辑。

## 错误处理

1. **客户端断开连接**：如果所有客户端断开连接，将使用最后一次成功获取的奖励值
2. **服务器关闭**：训练结束时服务器自动关闭，客户端应妥善处理连接断开情况
3. **奖励计算出错**：客户端应处理可能的错误，确保始终返回有效的奖励值

## 测试与验证

可以使用以下脚本测试外部奖励系统：

```bash
# 测试基本套接字通信
python test_basic_socket.py

# 测试简化版外部奖励系统
python test_simplified_reward.py

# 测试完整的外部奖励系统
python test_simple_external_reward.py
```

这些测试脚本可以帮助验证外部奖励系统的正常工作。
